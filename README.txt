GOA MIDI ARCHITECT - VST3 Source & Auto-Build Package
=====================================================

Option 1 (Easiest - No Visual Studio needed):
1. Create a free GitHub repository and upload all files in this folder (including .github/workflows/build.yml).
2. Open the "Actions" tab on GitHub -> Run "Build GoaMidiArchitect VST3 (Windows)".
3. Download "GoaMidiArchitect-Windows-VST3" and copy GoaMidiArchitect.vst3 to:
   C:\Program Files\Common Files\VST3\

Option 2 (Local Windows Build):
1. Install CMake and Visual Studio 2022 (Desktop development with C++).
2. Double-click build_windows.bat.
3. Copy GoaMidiArchitect.vst3 to C:\Program Files\Common Files\VST3\
